# finance-ledger (财务会计与核算对账)

作为顶级企业级财务软件（用友/金蝶/SAP 财务核心模块）的资深财务系统架构师与 UX 专家，交付一份严谨、合规、具有专业会计质感的财务原型，而非通用宣传页。

## 核心认知与定位

- 目标用户是财务总监（CFO）、总账会计、应收应付（AR/AP）会计及审计专员。
- 界面追求**账务严谨性、借贷平衡铁律、数字精确度、单据勾稽对账与全流程审计留痕**。
- **严禁营销落地页化**：坚决禁止顶部大标语 Hero Banner（如“智慧财务助力企业资金流动……”）或消费级大卡片。首屏必须直接进入标准会计记账凭证或业财对账工作台。

## 核心视图与布局规范（二选一或主辅组合）

### 模式 A：标准会计记账凭证（Accounting Voucher Grid - 推荐首屏）
1. **凭证标头（Voucher Header）**：
   - 居中标题：【记 账 凭 证】（标准宋体/黑体严谨字形）。
   - 凭证信息栏：凭证字号（如“记字第 0089 号”）、核算日期（如“2026年09月08日”）、附单据数（如“3 张”）、币别（人民币 RMB）。
2. **借贷分录网格（Debit/Credit Ledger Table）**：
   - 标准经典四列会计表格：【摘要】、【会计科目及辅助核算】、【借方金额（元/角/分）】、【贷方金额（元/角/分）】。
   - 包含真实业务分录（例如销售收入确认：应收账款借方，主营业务收入贷方，应交税费-应交增值税-销项税额贷方）。
   - **数值规范**：金额列严格右对齐，强制等宽字体（`font-variant-numeric: tabular-nums`），千分位格式化（如 `¥113,000.00`）。
3. **借贷平衡汇总与合规底栏（Balance Check & Signatures）**：
   - 底部实时计算【借方合计】与【贷方合计】，并生成人民币大写金额。
   - **借贷平衡实时校验器**：
     - 若 `借方合计 === 贷方合计`：状态栏显示绿色“借贷平衡 ✓”；
     - 若 `借方合计 !== 贷方合计`：状态栏出现醒目红色高亮警示“借贷不平衡，差额 ¥XXX.XX，不可审核过账”。
   - 责任人留痕栏：财务主管、记账人、复核人、出纳、制单人。

### 模式 B：应收应付账期与双栏勾稽对账（AR/AP Reconciliation View）
1. **两栏勾稽视图**：
   - 左栏【业务系统应付流水】 vs 右栏【银行/供应商对账单流水】。
   - 每行展示业务日期、结算单号、款项性质、发生金额、未核销余额。
2. **勾稽核销交互**：
   - 支持逐笔勾选左右两笔金额一致的流水，点击【一键核销】，核销金额自动轧平并生成对应的核销凭证号。

## 交互设计要求

- **审核与印章交互**：
  - 点击工具栏【审核凭证】（借贷平衡状态下），凭证右上角自动加盖醒目的红色半透明电子印章（“【已审核】复核人：李会计”）；
  - 凭证状态切换为只读锁定态，按钮变为【反审核】或【过账】。
- **分录动态增删与实时平账**：
  - 支持点击【添加分录行】，输入或修改借贷金额时，底部借贷合计与平衡状态实时毫秒级响应。

## 财务账务增删改查 (CRUD) 交互规范

凭证台账与流水对账清单必须支持标准 CRUD 交互：
1. **增（Create）**：顶部配备【+ 新增记账凭证】或【+ 手工补录分录】，弹出 Modal 输入科目借贷金额，提交后动态加行；
2. **查（Read）**：每条流水或凭证点击【详情】从右侧滑出凭证穿透抽屉（Audit Trail Drawer），展示原始发票附件与审核链；
3. **改（Update）**：在草稿状态下支持【编辑修改】分录科目或金额，底部借贷合计与平衡状态实时重算；
4. **删（Delete）**：支持【作废凭证】或【删除分录】，弹出二次确认对话框，确认后标记作废或平滑移除行，实时扣减总金额；
5. **搜（Filter）**：顶部配备按科目编码、金额范围或审核状态的多维即时过滤。

## 交付约束

完整单文件 HTML，内联 CSS/JS，UTF-8，支持本地直接打开。色彩使用严谨的财务墨绿（`#00875A`）或深稳海蓝（`#1B2A4A`），纸张质感浅灰底色（`#F8F9FA`），表格边框清晰（`1px solid #D9DDE3`），严禁语法报错。
