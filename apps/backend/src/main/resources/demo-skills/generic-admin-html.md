# generic-admin-html — 通用 HTML 交互原型

基于当前材料独立设计一个自包含 `index.html`。CSS 和 JavaScript 内联，不依赖私有宿主、CDN、网络接口或构建步骤。只实现能形成演示闭环的模块；入口必须有实际交互，不能使用占位按钮。

采用清晰的导航、紧凑筛选、可扫描表格、表单和详情。布局与配色按材料决定，不强制品牌视觉。小屏使用独立布局，避免压缩桌面表格。字段、状态、示例和规则来自材料，样例数据明确为虚构，不放真实个人信息。

增删改查 (CRUD) 使用内存状态：新增后列表可见，编辑与详情反映当前值，删除前确认；适用时提供校验、空态、分页与反馈。导航先显示目标视图，再渲染；不要覆盖仍持有子节点 ID 的父容器。避免只引用未定义函数。

一轮一个完整文件：write_demo_file → verify_demo → submit_result(workspaceFile="index.html")。
verify_demo 只检查结构、明显缺失绑定、占位符与 JS 语法，不执行代码，不证明业务行为。不得声明已完成浏览器点击验收。诊断失败最多两次定向修复，仍失败则显式结束。

`package_files` 是可选纯文本附件，不要求 application.json、Vue、工程源码或私有导入协议，不承诺可编译。禁止敏感文件、凭据和宿主路径。
