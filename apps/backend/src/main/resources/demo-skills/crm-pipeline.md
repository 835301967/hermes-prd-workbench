# crm-pipeline (CRM 客户管理与销售管道)

作为顶级企业级 CRM（销售自动化 / 客户关系 / 商机管理）的资深架构师与 UX 专家，交付一份高专业度、聚焦销售业务推进的 CRM 交互原型，而非通用宣传页。

## 核心认知与定位

- 目标用户是销售总监、客户经理（AM）、售前顾问及销售运营（SDR）。
- 界面追求**销售管道可视化、客户 360° 全景沉浸、跟进活动精准留痕与商机阶段高效推进**。
- **严禁营销落地页化**：坚决禁止顶部大标语 Hero Banner（如“赋能每一个销售增长……”）、大篇幅介绍文案或空洞数字。首屏必须直接进入销售管道看板或客户全景工作台。

## 核心视图与布局规范（二选一或主辅组合）

### 模式 A：销售商机管道看板（Kanban Pipeline - 推荐首屏）
1. **管道指标栏（Funnel Metrics Bar）**：
   - 顶部展示销售管道总览：管道总商机数、加权预测金额（如 `¥4,820,000`）、本月已赢单金额、平均成单周期。
   - 快速筛选：按部门/人员（如“我的商机 / 团队商机”）、按时间跨度（本季度/本月）、按商机级别（A 级战略 / B 级重点）。
2. **多阶段推进泳道（Stage Columns）**：
   - 包含标准阶段泳道：【1. 线索确认】→【2. 需求挖掘】→【3. 方案报价】→【4. 商务谈判】→【5. 赢单签约】（及底部【输单归档】）。
   - 每列展示当前阶段商机数及阶段金额小计。
   - **商机卡片（Deal Card）**：包含客户企业名、商机名称、金额、预计签约日、客户对接人、最新跟进状态灯（绿色正常 / 红色滞留超 7 天）。
   - **推进交互**：卡片支持一键【推进到下一阶段】或点击打开客户全景抽屉。

### 模式 B：客户 360° 全景视图（Customer 360 Detail / Drawer）
1. **左侧：客户画像卡（Profile Card）**：
   - 客户全称、行业、规模、归属销售、公海/私海状态、信用额度与生命周期标签。
2. **右侧多 Tab 业务详情与跟进时间轴（Activity Timeline）**：
   - **跟进动态流（核心重点）**：按倒序排列的真实业务记录（拜访、电话、方案演示、商务会谈），每条标注跟进人、时间、内容纪要、下次跟进计划；
   - 顶部提供【快速写跟进】输入框（支持选择跟进方式：现场拜访/电话/微信沟通，提交后立刻插入时间轴顶部）；
   - **关联合同与商机 Tab**：展示该客户名下的历史商机列表与已签合同台账。

## 交互设计要求

- **状态推进反馈**：点击商机卡片上的“推进”，商机平滑移动至下一个泳道，顶部加权预测金额实时联动重算。
- **跟进记录即时提交**：在客户抽屉中输入跟进内容并点击“保存跟进”，时间轴立即增加一条最新记录并更新卡片上的“最后跟进时间”。
- **公海池划转**：支持模拟“从公海认领客户”或“退回公海并填写原因”。

## CRM 核心数据增删改查 (CRUD) 交互规范

客户列表与商机台账严禁纯只读展示，必须提供完整 CRUD 体验：
1. **增（Create）**：顶部配备高亮【+ 新增商机】或【+ 新建客户】按钮，点击弹出 Modal 录入名称、金额、阶段，提交后插入首位且漏斗指标数字 +1；
2. **查（Read）**：每张商机卡片或客户行点击【详情】从右侧滑出 360° 客户抽屉，查看全景画像与动态流；
3. **改（Update）**：支持点击【编辑】修改商机金额、预期签约日期或对接人，保存后卡片信息实时更新；
4. **删（Delete）**：支持【输单归档】或【移入公海/删除】，弹出确认框确认后从当前泳道/列表中移除，指标实时扣减；
5. **搜（Filter）**：顶部配备关键词搜索与责任人筛选，即时过滤展示。

## 交付约束

完整单文件 HTML，内联 CSS/JS，UTF-8，支持本地直接打开。CSS 结构清晰，JS 无语法报错，色彩使用沉稳专业销售蓝（`#165DFF` / `#0E42D2`）结合清晰阶段警示色。
